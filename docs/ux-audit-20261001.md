## Ownership state

`src/core/commands.js` memiliki satu runtime untuk Tool/Snap/Zoom, View/Follow,
selection, playback/Loop. `src/app.js:986` merefleksikan Tool/Snap Piano dan Drum.
Drum belum memakai nilai Zoom runtime. `src/ui/studio.js` menyimpan panel presentasi saja;
membuka panel tidak mengubah canonical Song atau selection. Undo menangani operasi canonical;
view/selection/clipboard/loop tidak masuk history. Input/textarea/select/contenteditable,
composing dan repeat memiliki guard shortcut. Tidak mengambil Ctrl+Plus/Minus.

Potensi handler keyboard Score ganda dari pembacaan source tidak terkonfirmasi oleh
ArrowUp runtime (A4→A#4). Perlu pengujian Alt+Arrow dan Delete sebelum menyebutnya bug.

## Prioritas Tahap 1

Tiga masalah: (1) grid terlambat dimulai karena pita identitas/overview/chrome,
(2) alat chord dan clone mix permanen mengambil ruang dari edit melodi,
(3) transport mobile terlalu tinggi dan Play/Pause terpisah.
Pertahankan tab mode yang sudah sehat, pindahkan node/hook tanpa clone,
gunakan playback state untuk toggle, dan ukur resize/panel transition.
Tidak menyentuh schema Song, Share, generator internals atau audio engine.
Expression/selection workflow serta gesture masuk tahap berikutnya.

# Melodi Ronde 2 — UAT pemilik

UAT fisik belum dijalankan. Gunakan halaman GitHub Pages setelah deploy atau build lokal yang sama. Bukti kode dan preview ada di [checkpoint2-stage2.md](checkpoint2-stage2.md); screenshot implementasi ada di folder [evidence/after](evidence/after/).

## Cara mencatat

Gunakan desktop pada 1280×800 dan ponsel pada 390×844. Untuk J7, pegang ponsel dengan satu tangan. Mulai dari lagu uji baru agar perubahan dan aksi Hapus tidak menyentuh lagu tersimpan. Catat setiap ketukan, klik, atau sapuan sebagai satu gestur; hitung mengetik lirik sebagai satu sesi input, lalu catat waktunya terpisah. Jalankan stopwatch dari instruksi tugas sampai hasil terdengar/tersimpan. Catat `NOT VERIFIED` bila audio tidak dapat dinilai. Simpan screenshot atau rekaman hasil ke folder `evidence/after/` sebelum mengubah status.

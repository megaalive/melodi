## Masalah dan keputusan

1. Canvas belum memiliki pinch/pan dua jari. Modul navigation capture membatalkan
   pending draw/move/resize/marquee/ruler sebelum dua jari mengambil alih. Gesture
   mengubah zoom editor melalui command yang sudah ada dan scroll viewport, tanpa
   state musik kedua. Klik susulan ditahan sampai 400ms setelah jari terakhir lepas.
   Ctrl+wheel membatalkan edit pointer aktif sebelum mengubah geometri. Wheel biasa
   tetap native. Touch-action none dibatasi canvas; bagian halaman lain tetap native.
2. Long press 550ms pada note membuka context menu asli; pada hit membuka panel
   Expression asli. Gerak >8px, scroll, jari kedua, pointercancel membatalkan hold.
   Tidak ada double tap untuk insert di Select. Piano zoom 50–400%; Drum minimum
   100% menjaga sel minimal 44px di touch/tablet, maksimum 400%.
3. Shortcut global sebelumnya tidak menghormati defaultPrevented. Guard sekarang
   menjaga event Score lokal agar tidak diproses dua kali. Space pada canvas menjadi
   Play/Pause; input, textarea, select, contenteditable, composition, repeat, tombol,
   link dan summary tetap menggunakan aksi native/lokal. Pitched copy/paste global
   dilewati dalam Drum. Shortcut generation 1–8 ditampilkan pada tombol Audition;
   Accept memberi title Enter. Ctrl+Plus/Minus browser tetap tidak diambil alih.

Tujuh key English Select/Draw yang hilang ditambahkan. Overview cache sekarang
memperhitungkan bahasa sehingga aria-label seek langsung diterjemahkan. Bend range
menyebut unit semitone. Help ID/EN menjelaskan gesture. README dikoreksi dari

Lyrics writing + mapping juga sudah ada dan tidak diimplementasikan ulang.
